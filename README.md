# ClandestineRaces (RDR2, single-player)

Mod de corridas clandestinas de cavalo com apostas, escrito em Lua para o RedLua.

## Estrutura

- `Scripts/ClandestineRaces/` : scripts Lua. A pasta inteira vai para `RedLua\Scripts\` na instalação do jogo.
- `.gitignore` : exclui logs e arquivos gerados em runtime.

## Status

- Etapa 0: repositório criado. Compatibilidade do RedLua com o jogo ainda não confirmada.

## Instalação (para teste)

Copiar `Scripts\ClandestineRaces` para `<pasta do jogo>\RedLua\Scripts\ClandestineRaces`.

Só para single-player. Não usar no modo online.
